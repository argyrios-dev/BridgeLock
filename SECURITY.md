# Security Policy

## Supported Versions

Only the latest release is supported with security updates.

| Version | Supported |
| ------- | --------- |
| Latest  | ✅ |
| Older   | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability in BridgeLock, please do not open a public GitHub issue.

Instead, report it privately by opening a GitHub Security Advisory or by contacting me directly.

Please include:

- A description of the vulnerability.
- Steps to reproduce it.
- The affected macOS version.
- The BridgeLock version.
- Any proof of concept, logs or screenshots that help reproduce the issue.

I will acknowledge receipt as soon as possible, investigate the report, and work on a fix before any public disclosure.

Thank you for helping keep BridgeLock secure.
